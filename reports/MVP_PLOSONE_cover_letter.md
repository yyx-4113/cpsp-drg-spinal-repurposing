# Cover Letter — PLOS ONE

**Manuscript title:** Conserved nerve-injury-associated transcriptional response on the dorsal root ganglion–spinal axis: non-predictive incision translation and an honest repurposing null

**Corresponding author:** Yang Y, The Second Affiliated Hospital of Fujian University of Traditional Chinese Medicine, Fuzhou, Fujian 350003, China. ORCID 0009-0004-9698-6552. Email: 960856791@qq.com

**To the Editorial Board of PLOS ONE,**

I submit the original research article above for consideration as a Research Article. This is a purely computational, multi-dataset reanalysis of publicly available transcriptomes that produces new integrative findings and a reproducible benchmark for the chronic postsurgical pain (CPSP) dorsal root ganglion–spinal (DRG–spinal) axis. It is submitted as primary research: the work generates a novel integrative signature, a non-circular translation test, a prospectively specified full-library drug-repurposing screen with reverse controls, and an explicit bootstrap stability assessment—not a review or re-statement of prior results.

**Why PLOS ONE is the right venue.** PLOS ONE's editorial criteria evaluate scientific rigour and reproducibility rather than perceived novelty or impact, and the journal explicitly welcomes transparent negative and null results. This manuscript is built around exactly those principles. (i) The analysis was pre-specified and registered in the public repository before reporting: the repurposing screen was defined as a full-library breadth analysis with reverse positive controls before any enrichment was computed. (ii) Rigour is reported as results, not footnotes: a DerSimonian–Laird random-effects sensitivity analysis shows the core signature shrinks from 4,055 to 1,008 genes (median I² = 38.8%) and that OXPHOS suppression does not survive set-level Benjamini–Hochberg correction under random effects (q = 0.31); a non-circular test demonstrates the nerve-injury signature does *not* predict incision direction (46.3% versus 47.1% background; −0.9 pp, permutation p = 0.14); and a bootstrap shows the docking target set is not statistically reproducible (median 1 of 17 dock-eligible hubs recovered per resample), so target selection rests on structural tractability. (iii) The full-library docking of 3,085 FDA drugs against 10 tractable targets yields an honestly negative result—no target clears both the raw/full-library and size-independent filters (ADRA2A Tier-1 AUC 0.618 collapses to 0.532, p = 0.118)—which we report as a methodological boundary rather than a false-positive hit, including a demonstration of how inadequate controls generate double-dipping false positives.

**Reproducibility and openness.** All processed data and analysis code are released in the public GitHub repository at https://github.com/yyx-4113/cpsp-drg-spinal-repurposing (tag v1.0.0; file integrity verifiable via MANIFEST.sha256). No "available on request" statement is used; all underlying primary data are in the public GEO repository. The manuscript includes the PLOS ONE-required Author Summary, Data Availability, Ethics, Funding, Competing Interests, and Author Contributions statements.

**Compliance with PLOS ONE policies.** This is original work, not published elsewhere and not under consideration by another journal. No new human or animal data were generated; only public, de-identified GEO data were reanalysed, and an ethics statement to this effect is included. No funding was received for this work (it is preliminary foundation for a pending grant application, with no grant number). The author declares no financial competing interests; a pending Fujian Natural Science Foundation grant application lists ADRA2A among candidate targets but did not fund and did not influence the present analyses, results, or conclusions. A large language model assisted language drafting; all scientific content is solely the author's.

We confirm the author approves submission.
